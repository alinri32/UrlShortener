# سرویس کوتاه‌کننده لینک مقیاس‌پذیر (High-Performance URL Shortener)

این پروژه یک وب‌سرویس سریع و بهینه‌سازی‌شده برای کوتاه‌سازی و ریدایرکت لینک‌ها است که بر پایه دات‌نت طراحی شده است. هدف اصلی این سرویس پاسخ‌دهی به ترافیک بالای روزانه (میلیونی) با حداقل تأخیر (Low Latency) و تضمین عدم تداخل شناسه‌ها در محیط‌های توزیع‌شده است.

---

## 🎯 اهداف و ویژگی‌های کلیدی

* **ظرفیت پردازشی بالا:** بهینه‌سازی شده برای ثبت و خواندن سریع بدون ایجاد گلوگاه (Bottleneck).
* **کدگذاری Base62 بدون سربار رم (Zero-Allocation):** استفاده از `ReadOnlySpan<char>` و `stackalloc` جهت تبدیل شناسه‌ها بدون درگیر کردن Garbage Collector.
* **تخصیص بازه‌ای شناسه‌ها (Range-Based ID Allocation):** دریافت شناسه در بلاک‌های مشخص از دیتابیس و مدیریت اتمیک در حافظه بدون Race Condition.
* **محافظت در برابر Cache Stampede:** به‌کارگیری الگوی Single-Flight در لایه ردیس جهت ممانعت از هجوم درخواست‌های هم‌زمان به دیتابیس در زمان انقضای کش.
* **امنیت و احراز هویت منعطف:** پشتیبانی از احراز هویت توکن JWT و همچنین احراز هویت کلید دسترسی (API Key) با ذخیره‌سازی امنِ هش‌شده SHA-256.
* **محدودسازی نرخ درخواست (Rate Limiting):** جلوگیری از حملات Brute Force و سوءاستفاده از منابع با سیاست Fixed Window.

## 🛠 ابزارها و فناوری‌ها

* **فریم‌ورک هسته:** .NET 10
* **پایگاه‌داده رابطه‌ای:** Microsoft SQL Server
* **میکرو ORM:** Dapper
* **حافظه موقت (Cache):** Redis (StackExchange.Redis)
* **اعتبارسنجی:** FluentValidation
* **تست‌های واحد و هم‌روندی:** xUnit، NSubstitute، FluentAssertions
* **مستندسازی API:** Swagger / OpenAPI
